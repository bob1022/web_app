# Astronomy Tools Dashboard

## Description

Astronomy web application for distance conversion,
travel-time calculations, and astronomy tools.

## Features

- Travel Time Calculator
- Distance Converter
- Astronomy Dashboard
- Stellarium integration support

## Technologies Used

- Python
- Flask
- HTML/CSS
- JavaScript

## Installation

1. Clone repository
2. Create virtual environment
3. Install requirements
4. Run app.py
